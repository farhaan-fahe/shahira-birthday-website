# 🌸 Shahira Banu — Interactive Birthday Scrapbook Website 🎂

A mobile-first, Pinterest-stationery and K-drama scrapbook inspired interactive birthday celebration website built with HTML5, Vanilla CSS3, and Vanilla JavaScript.

---

## ✨ Features & Visual Journey

1. **Stationery Hero & Cake Scene**: Warm ivory paper, black ribbon bows, hand-drawn ink birthday cake, delicate stars, and stationery typography.
2. **Interactive Candle**: Tap the candle or button to blow it out — triggers rising smoke, ambient star sparkles, and pastel celebration confetti.
3. **Chapter 01 — Dedicated Birthday Wish**: Warm stationery letter presentation with personal birthday dua and wishes.
4. **Cinematic 3D Envelope**: Realistic folded ivory envelope with wax seal that unfolds upon interaction and reveals the handwritten letter.
5. **Long Handwritten Letter**: Personal stationery parchment with deckled torn edges and signature.
6. **Chapter 02 — Playful Mini-Games**:
   - **Dots & Boxes**: Interactive turn-based game (Player vs Memory Bot or 2-Player).
   - **Drawing Together**: Sketchpad canvas with color palettes, brush sizes, floral stamp, eraser, and doodle download.
7. **Our Sticky Love (K-Drama Scrapbook)**: Clothesline photo arrangement with five hanging Polaroid photos clipped by wooden clothespins to a curved twine cord, featuring tap-to-zoom interaction.
8. **Chapter 03 — Melodies & Atmosphere**: Custom vinyl record audio player with local MP3 playback (Cinnamon Girl, Die For You Remix, 7 rings), real-time progress bar, seeking, and interactive playlist.
9. **Starry Night Keepsake Ending**: Dynamic celestial canvas with glowing stars, floating lanterns, and silent wish sender.

## 🚀 Running Locally

Open `index.html` directly in any modern browser, or run a local static server:

```bash
# Using Python:
python -m http.server 8000

# Using Node.js:
npx serve .
```

Open `http://localhost:8000` in your web browser.
